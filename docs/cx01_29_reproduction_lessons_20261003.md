# CX-01 至 CX-29 可复现实验经验

本文是长期保留的精炼经验索引，记录 CX-01 至 CX-29 中值得复现的负结果、诊断和失败原因。权威实验总账见[训练实验总账](training_experiment_ledger.md)；逐轮机制、启动审计和原始证据说明见[CX-01 至 CX-28 报告](../reports/cx01_28_diagnostics_20261003.md)与[CX-29 报告](../reports/cx29_trap_routes_20261003.md)。原始 `runs/` 产物不进入版本库。

## 证据口径

- **64 局快筛**：固定评估 seed、相同出生、greedy、300 tick，分别对 Tactical v2、真实网页 hunter `hard`/`normal`/`easy` 评估。它只用于淘汰和选择保存点，不能证明收益或触发长训。
- **512 局确认**：使用独立评估 seed，每个模型每个 Bot 512 局，同出生配对和 10,000 次 paired bootstrap；原点与独立训练 seed 都必须通过预登记门槛。二者不能混为一个样本。
- `S/T/D/B` 分别表示 surviving non-trade kill、trade、own-bomb death 和 bombs/game。hard/normal 的零或低 `S` 不能单独证明退化，也不能被 easy、生存或少自炸替代。

## 按类别归档

表中“跨 seed”只在独立训练 seed 的结果支持时填写“复现”；只有原点、64 局或代理 JAX 信号时明确标为“未复现/不适用”。

### 奖励、信用与价值路径

| 实验 | 假设 / 唯一变量 | 真实四 Bot 结果；跨 seed | 失败模式与以后避免 |
|---|---|---|---|
| CX-01, CX-02, CX-05, CX-06 | 分别改变 GAE 延迟、安全结算、临爆 pressure 或 actor/value 梯度路径，每次只改一个因素。 | 64 局均未形成稳定候选；无 512 局复现。 | 延长 credit、删奖励或只读梯度诊断都没有网页攻击转化；必须先看绝对基线和末期安全性。 |
| CX-10, CX-11 | 调整正向塑形尺度（含 `.3/.6` 消融）。 | 快筛有点状通过；原点或独立确认的 Tactical 门槛失败，未跨 seed。 | 放泡增多不等于安全击杀；不把相对失败臂的改善写成收益。 |
| CX-20, CX-22, CX-23 | 提高 surviving-kill reward、做 `24/48` 消融或改变 EMA。 | 原点和部分重训综合 C 为正，但 Tactical 下界失败，CX-22 还出现 hard trade。 | 停止单向加击杀奖励；逐格 S/T/D/B 必须和综合 C 一起过门槛。 |
| CX-25 | 只投影 HL-Gauss value target 到固定支持区间。 | 两次 512 局综合 Delta C `+.205/.156`，但 hard S 均 `0/512`；安全收益跨 seed 复现，hard 攻击未复现。 | 价值标签稳定不代表网页攻击改善；保留 hard 限制。 |
| CX-28 | 只增加按敌方安全首步缩减计的 margin reward `.4`。 | 64 局两臂各 2/8 通过、全部 hard S=0；原点 Delta C `+.150`，独立 `-.230`，未复现。 | JAX 静态逃路近似不能代替真实网页猎手；不要把 control 候选归因给新奖励。 |

### 对手、几何与攻击机制

| 实验 | 假设 / 唯一变量 | 真实四 Bot 结果；跨 seed | 失败模式与以后避免 |
|---|---|---|---|
| CX-03, CX-07 | 将 P1 改为 current/frozen 或提高 JAX `hunter_hard` 比例。 | 快筛无稳定 hard/normal 改善；无确认复现。 | JAX 强对手不是真实 JS hunter 的等价物。 |
| CX-08, CX-09 | 清砖，或在清砖后改变强规则对手占比。 | CX-09 原点通过但独立 seed 未复现；清砖降低自炸同时 Tactical 攻击下降。 | 几何与对手变量必须拆开；防御收益不能以攻击塌缩换取。 |
| CX-14, CX-16 | 改规则对手难度，或加入相邻格反制泡预判。 | 原点综合分有正信号，独立 Tactical 下界失败；无跨 seed hard 改善。 | 局部 JAX 机制不覆盖完整网页猎手；不要用瞬时 threat 替代结算击杀。 |
| CX-21, CX-24, CX-27 | current/frozen 学习型 P1、sampled/greedy 解码或固定强 reference。 | 各有 64 局候选，但独立确认 Tactical 失败；hard S 未改善。 | 对手强度/解码改变不能单独证明网页泛化。 |
| CX-29 | 仅把 50% JAX `hunter_hard` 的目标场加入至多 16 个非射线 trap 位置。 | 两次 512 局综合 Delta C CI 均大于零，Tactical S `201→230/229`；hard `4→0/0`、normal `0/0/0`，安全收益跨 seed 复现但攻击未复现。 | it50 到 it101 的跨 seed 曲线退化；CX-30 的混合对手 gate 仍没有 hard S。禁止同配置长训。 |

|---|---|---|---|

### 诊断与流程经验

| 实验 | 假设 / 唯一变量 | 真实四 Bot 结果；跨 seed | 失败模式与以后避免 |
|---|---|---|---|
| CX-13 | 只改变 mixed/native 出生分布。 | 原点 Delta C `+.365`，独立 `-1.055`，未复现且自炸激增。 | 不用评测出生或相关轨迹拟合训练；分布改变必须做配对消融。 |
| CX-30 | 固定 trap16，只把 JAX `hunter_hard` 从 50% 提到 75%。 | 64 局 mixed-hard 8/16 保存点通过、3/4 seed 有多个通过点，但 hard S 全为 0，it201 Tactical S/B/P 下降；未做 512 局确认。 | 这是筛选信号而非攻击证据；不启动 401-update。 |
| CX-31/32 | 审计安全攻击机会，并把网页 forced 几何见证混入短训。 | 网页正常出生近距事件无 forced；人工起点可见机制，但两条 21-update 模型 hard/normal S 均 0/64；不适用跨 seed 晋升。 | 静态 JAX 标签与网页时间展开不一致；先做同状态配对和协议对齐，不能把人工见证当正常出生收益。 |

## 固化结论

1. 先用 64 局筛选，再用独立 seed 的 512 局确认；两种证据必须分开报告。
2. 每轮只改变一个可解释因素；失败实验代码只有在有通用依赖和回归测试时才进入 main，原始 run、临时控制文件和个人路径不进入版本库。
3. 任何长训前都要看到至少两个训练 seed、多个保存点的 hard 或 normal surviving non-trade kill，且 Tactical S/T/D/B 没有退化；更多放泡、更多 threat、少自炸或 easy 改善都不够。
4. CX-29 的安全收益可复现，但 hard/normal 击杀未改善，it50→it101 已出现退化，CX-30 也未补上转化。因此当前结论是**不值得按同配置启动 trap16 长训**；应先得到与真实网页 Hunter 时间展开机制对齐的单变量正信号。
