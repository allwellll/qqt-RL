# 开局模型加载进度（20261108）

根因：素材完成后的遮罩文案没有继续订阅模型 Worker 的下载进度。侧栏有字节进度，手机首屏遮罩却一直显示“素材就绪，正在开局…”。Worker 原来没有向 UI 传递来源切换、校验、ORT 初始化阶段。

## 变更

- 首次开局及中途切换已发布模型都显示遮罩，下载时同步显示模型名、已下载/总 MB、百分比；总长未知时仅显示已下载量。侧栏保留同样进度。
- 按真实下载来源事件提示“主线路较慢或不可用，改用备用线路…”，不泄漏下载异常中的本机信息。
- 下载后显示“下载完成，正在校验并初始化模型…”，ORT/JSON 初始化时显示“正在初始化模型…”，首帧后撤罩。
- 失败保留遮罩和实际原因，提供“重试”；不会失败后自动隐藏或冒充模型就绪。重试沿原来源顺序执行，旧模型若存在保留到替代模型成功加载再释放。
- 模型等待/失败时暂停游戏推进，清掉当前操作；正常游戏物理、规则、模型观察不变。
- 为避免缓存读取闪现0–100%，下载文案在流读取持续600ms后才显示；快速读取直接显示初始化。连接等候不计入流读取延迟。保留浏览器默认HTTP缓存，不新增模型资产或更换下载源/大小。
- 只向 Worker/UI 扩展阶段通知，不增加额外校验下载；原运行时完整性校验保留。源码闭包清单仅更新 app.js 内容哈希，没有改训练。

## 最小验证

通过 `node web/test_model_loader.js`、`node web/test_model_worker.js`、`node web/test_controls.js`、`node web/test_ui_panels.js`、源码闭包审计和 `git diff --check`。

真实 Chromium 390×900手机视口，实际默认SP ONNX（30,276,775字节）：测试专用 Worker 对响应流限速4 MiB/s，观察到188次下载文字变化、递增百分比及实际校验/初始化阶段，随后进入游戏。不是Fast 3G预设，不冒称真机iOS。二次快速读取不出现下载百分比闪烁。注入所有ONNX来源HTTP403，遮罩显示失败及备用线路提示；点击真实“重试”按钮后恢复实际模型并进入游戏，无pageerror。失败界面截图及阶段收据在忽略目录 `.hermes/loading-failure-mobile.png`、`.hermes/loading-browser.json`。

本地测试使用请求拦截访问预览，因此不把本地快速二次读取称作已证实HTTP缓存命中；上线后使用不拦截请求的线上Chromium回读版本并检查缓存事件，最终证据存本地交付回执。遮罩文本自适应换行，不超出手机视口，普通输入框未改。
